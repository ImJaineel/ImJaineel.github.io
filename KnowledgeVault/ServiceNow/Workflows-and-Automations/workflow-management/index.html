Workflow Management & Flow Approvals

ServiceNow provides both legacy Workflows and modern Flow Designer for automation. Managing these effectively sometimes requires scripting—whether you are digging through legacy workflow data to find specific values, reverting versions programmatically, or writing advanced scripted approvals in Flow Designer.

1. Searching Across Legacy Workflow Activities (Background Script)​

If you need to find where a specific keyword (like an old email address or a specific URL) is used across all published workflow activities, you can query the variable values linked to workflow activities.

APIs Used:

  • GlideRecord('sys_variable_value') - Where activity values are actually stored.
  • GlideRecord('wf_activity') - To get the workflow version context.
javascript
var keyword = "some_search_term"; // Keyword to search for

// Construct partial matching query
var query = "valueLIKE" + keyword;
var workflows = {};

var tbl = new GlideRecord("sys_variable_value");
try {
    tbl.addEncodedQuery(query);
    tbl.query();

    while (tbl.next()) {
        var wftbl = new GlideRecord("wf_activity");
        // Link the variable value to the activity via document_key
        wftbl.addQuery("sys_id", tbl.document_key);
        wftbl.addEncodedQuery("workflow_version.published=true");
        wftbl.query();

        if (wftbl.next()) {
            var workflowName = wftbl.workflow_version.name ? wftbl.workflow_version.name.toString() : "Unknown Workflow";
            var activityName = wftbl.name ? wftbl.name.toString() : "Unknown Activity";

            if (!workflows[workflowName]) workflows[workflowName] = [];
            workflows[workflowName].push(activityName);
        }
    }

    // Output results as JSON
    var result = { result: [] };
    for (var workflow in workflows) {
        result.result.push({
            wfname: workflow,
            activityname: workflows[workflow]
        });
    }
    gs.info(JSON.stringify(result, null, 2));

} catch (error) {
    gs.error("An error occurred during processing: " + error.message);
}

2. Reverting a Workflow Version Programmatically (Background Script)​

If a newly published workflow version is causing issues, you can programmatically unpublish it and republish an older version by updating the wf_workflow_version table.

APIs Used:

  • GlideRecord('wf_workflow_version')
javascript
// Step 1: Unpublish the current broken version
var getWfBad = new GlideRecord('wf_workflow_version');
if(getWfBad.get('<current_version_sys_id>')) {
    getWfBad.published = false;
    getWfBad.update();
}

// Step 2: Publish the old stable version
var getWfGood = new GlideRecord('wf_workflow_version');
if(getWfGood.get('<old_version_sys_id>')) {
    getWfGood.published = true;
    getWfGood.update();
}

3. Scripted Approvals in Flow Designer​

While Flow Designer allows low-code approvals, you may encounter complex scenarios requiring script. The "Ask for Approval" action accepts a specific string syntax to build rules dynamically.

[!NOTE] Consider scripting as a last resort. Check out the Flow Approval CoE before writing custom approval scripts.

Syntax Structure​

The syntax is built by concatenating the following string elements: [Ruleset] + [Rule] + [Who] + [sys_id list]

Rulesets:

  • Approves
  • Rejects
  • ApprovesRejects

Rules:

  • Any (Anyone approves)
  • All (All users approve)
  • Res (All responded and anyone approves)
  • % (% of users approve)
  • # (Number of users approve)

Who:

  • U (Users)
  • G (Groups)

Examples​

Approval ScenarioScript String Syntax
Approved by any UserApprovesAnyU[user_sys_id,user_sys_id]
Approved by 50% of GroupApproves50%G[group_sys_id]
Approved by 2 Users or by GroupApproves2#U[user1_id,user2_id]G[group_sys_id]
Rejected by all UsersRejectsAllU[user_sys_id,user_sys_id]
Approved or Rejected by any UserApprovesRejectsAnyU[user_sys_id]
Approved by Group OR Rejected by any UserApprovesAnyG[group_sys_id]OrRejectsAnyU[user_sys_id]
All responded and anyone approves in GroupApprovesResG[group_sys_id]

Example usage in a Flow Action Script:

javascript
// Example: Dynamically require 1 person from a specific group to approve
var groupSysId = fd_data.trigger.current.assignment_group.sys_id;
return "ApprovesAnyG[" + groupSysId + "]";
