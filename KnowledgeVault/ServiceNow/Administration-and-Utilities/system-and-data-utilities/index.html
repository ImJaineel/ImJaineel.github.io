System & Data Utilities

This article covers miscellaneous system-level utilities in ServiceNow, including impersonating the "System" user, manipulating time formats, canceling records in bulk, and decrypting credentials.

1. Impersonating the System User & Managing Time​

Sometimes background tasks or bulk updates need to bypass user security rules or be logged as the "System". Furthermore, understanding how GlideDateTime formats time in UTC vs Local Server Time is crucial.

APIs Used:

  • gs.getSession().impersonate("system") - Bypasses standard user context.
  • GlideDateTime - Handles time manipulation.
javascript
// Impersonate the System user
var systemUser = gs.getSession().impersonate("system");

var gdt = new GlideDateTime(); // Always UTC +0
gs.print("UTC Time: " + gdt.getValue()); 
gs.print("Timezone Offset (ms): " + gdt.getTZOffset()); // Difference from UTC
gs.print("Server Internal Format: " + gdt.getDisplayValueInternal()); // Local time in yyyy-MM-dd HH:mm:ss
gs.print("Local Formatted Time: " + gdt.getDisplayValue()); // Local formatted time based on session

// Revert back to the original user
gs.getSession().impersonate(systemUser);

2. Canceling Incidents in Bulk as System​

When performing mass updates (like canceling incidents after a monthly maintenance window), running it as the "System" ensures you don't trigger unnecessary notifications designed for human agents, and audit logs correctly attribute the change to the system.

APIs Used:

  • gs.getSession().impersonate()
  • GlideRecord update operations.
javascript
var cancel_note = 'This failure alert is due to monthly maintenance activity. By default post maintenance, we have already rerun all the failed jobs, which went to success and hence we are canceling this incident. Cancelled from backend by SNC Team.';

var grIncident = new GlideRecord('incident');
grIncident.addEncodedQuery("number=INC16349771"); // Example target
grIncident.setLimit(50);
grIncident.query();

while (grIncident.next()) {
    // Impersonate system before the update
    var originalUser = gs.getSession().impersonate("system");
    
    grIncident.incident_state = 8; // Cancelled
    grIncident.comment = cancel_note;
    grIncident.close_notes = cancel_note;
    grIncident.update();
    
    // Immediately revert impersonation
    gs.getSession().impersonate(originalUser);
}

3. Decrypting Stored Passwords​

In advanced integration or troubleshooting scenarios, you might need to decrypt a password stored securely in a ServiceNow credentials record or an encrypted field.

APIs Used:

  • sn_cc.StandardCredentialsProvider() - Modern API for fetching credentials securely.
  • GlideEncrypter() - Lower-level API for decrypting specific encrypted fields.

Option 1: Using Standard Credentials Provider

javascript
// Fetch password from the Discovery/Orchestration Credentials table
var provider = new sn_cc.StandardCredentialsProvider();
var credentials = provider.getCredentialByID("<credential sys_id>");
var password = credentials.getAttribute("password");
gs.info("Decrypted Password: " + password);

Option 2: Using GlideEncrypter

javascript
// Decrypt a specific Two-Way Encrypted field (e.g., jdbc_password)
var encrypter = new GlideEncrypter();
gs.log("Decrypted DB Password: " + encrypter.decrypt(grSDS.jdbc_password));
