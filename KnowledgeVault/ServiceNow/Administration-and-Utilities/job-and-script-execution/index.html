Job & Script Execution in ServiceNow

ServiceNow administrators frequently need to manage scheduled jobs, execute them in bulk, or troubleshoot jobs that are stuck. This guide explains how to programmatically handle these scenarios using Background Scripts.

1. Executing Scheduled Jobs in Bulk​

When dealing with multiple scheduled data imports, reports, or other scheduled items, it is tedious to trigger them manually. You can use the SncTriggerSynchronizer API to execute jobs programmatically.

APIs Used:

  • SncTriggerSynchronizer.executeNow(GlideRecord) - Forces a scheduled job to execute immediately.
  • GlideRecord - For querying the target jobs (e.g., scheduled_import_set or sysauto_report).

Example Script:

javascript
var table = 'scheduled_import_set'; // Or use 'sysauto_report' for reports
var field = 'data_source'; // Or 'report_title'
// Array of sys_ids for the data sources or scheduled jobs
var range = [
    '4096f49adba6b890c7cfc0a239961938',
    '3c373812dbe6b890c7cfc0a23996192f',
    'bfba3ba2db3c60108150b177f49619b4'
]; 

var gr = new GlideRecord(table);
// Dynamically build the encoded query for all sys_ids
gr.addEncodedQuery(`${field}=${range.join(`^OR${field}=`)}`);
gr.query();

while (gr.next()) {
    gs.info("Executing: " + gr.getDisplayValue());
    // Trigger the job immediately
    SncTriggerSynchronizer.executeNow(gr);
}

2. Finding Stuck Scheduled Jobs​

Sometimes scheduled jobs get "stuck" in a running or queued state, particularly if they are claimed by a node that no longer exists (e.g., after an instance clone or node restart).

This script checks the sys_trigger table for jobs claimed by invalid nodes.

APIs Used:

  • GlideRecord('sys_trigger') - The core table storing all scheduled and triggered events.
  • GlideRecord('sys_cluster_state') - Stores active node information.

Example Script:

javascript
showScheduledJobsStuckOnMissingNodes();

function showScheduledJobsStuckOnMissingNodes() {
    var gr = new GlideRecord('sys_trigger');
    
    // Query only jobs that are queued (1) or running (2)
    gr.addQuery('state', 'IN', '1,2');
    // Filter out those that are not claimed by any node
    gr.addQuery('claimed_by', '!=', 'NULL');
    
    // Check against valid nodes in the cluster
    var gr2 = new GlideRecord('sys_cluster_state');
    gr2.query();
    while (gr2.next()) {
        // Filter out any valid system_id values. What remains are invalid claims.
        gr.addQuery('claimed_by', '!=', gr2.system_id); 
    }
    gr.query();
    
    // Display a warning for each suspect scheduled job
    while (gr.next()) {
        gs.print('WARNING: sys_trigger.' + gr.sys_id + ' has a state of ' + gr.state + ' and is claimed by missing node: ' + gr.claimed_by);
    }
}
