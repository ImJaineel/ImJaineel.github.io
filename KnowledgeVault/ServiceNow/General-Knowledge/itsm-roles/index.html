ITSM Roles

This plugin loads a supplementary security model to the itil role that allows specific roles to be assigned for each application in the ITSM suite. ITSM Roles - Incident Management updates the Incident Management security model to factor two new roles: sn_incident_read and sn_incident_write ITSM Roles - Problem Management updates the Problem Management security model to factor two new roles: sn_problem_read and sn_problem_write ITSM Roles - Change Management updates the Change Management security model to factor two new roles: sn_change_read and sn_change_write ITSM Roles - Request Management updates the Request Management security model to factor two new roles: sn_request_read and sn_request_write IMPORTANT: This plugin loads new Access Controls for the applications listed above, read the release notes and documentation to understand the full impact of this plugin.
