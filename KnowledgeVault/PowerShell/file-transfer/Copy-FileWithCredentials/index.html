Copy-FileWithCredentials

Synopsis​

Maps a UNC path as a temporary PSDrive using explicit credentials and copies a file.

Description​

Creates a temporary mapped drive (Z:) using the provided $cred PSCredential, copies the source file to the mapped destination, then removes the drive in a finally block to ensure cleanup even on failure. $cred must be set in the caller scope (e.g., ServiceNow Orchestration or Get-Credential).

Parameters​

SourcePath​

Full path of the source file to copy.

DestinationUNC​

UNC path of the network share to map (without trailing backslash).

DestinationFile​

Filename to use at the destination.

DriveLetter​

Drive letter to use for the temporary mapping. Defaults to "Z:".

Examples​

Example 1​

powershell
$cred = Get-Credential
    .\Copy-FileWithCredentials.ps1 -SourcePath "D:\data.csv" -DestinationUNC "\\server\share" -DestinationFile "output.csv"

Author: Jaineel Petiwale

Script Code​

Copy-FileWithCredentials.ps1
powershell
<#
.SYNOPSIS
    Maps a UNC path as a temporary PSDrive using explicit credentials and copies a file.
.DESCRIPTION
    Creates a temporary mapped drive (Z:) using the provided $cred PSCredential,
    copies the source file to the mapped destination, then removes the drive in a
    finally block to ensure cleanup even on failure.

    $cred must be set in the caller scope (e.g., ServiceNow Orchestration or Get-Credential).
.PARAMETER SourcePath
    Full path of the source file to copy.
.PARAMETER DestinationUNC
    UNC path of the network share to map (without trailing backslash).
.PARAMETER DestinationFile
    Filename to use at the destination.
.PARAMETER DriveLetter
    Drive letter to use for the temporary mapping. Defaults to "Z:".
.EXAMPLE
    $cred = Get-Credential
    .\Copy-FileWithCredentials.ps1 -SourcePath "D:\data.csv" -DestinationUNC "\\server\share" -DestinationFile "output.csv"
.TAGS
    copy, unc, file-transfer, psdrive, pscredential, network-share, map-drive
.NOTES
    Author: Jaineel Petiwale
#>
param (
    [string]$SourcePath      = "D:\OneStream_RITMs\production\Onestream_RITM10255120.csv",
    [string]$DestinationUNC  = "\\sacnt2192.americas.ad.flextronics.com\OneStream_PRD_NativeAndWeb",
    [string]$DestinationFile = "Onestream.csv",
    [string]$DriveLetter     = "Z:"
)

$driveName = $DriveLetter.TrimEnd(':')

try {
    New-PSDrive -Name $driveName -PSProvider FileSystem -Root $DestinationUNC -Credential $cred -ErrorAction Stop
    Copy-Item -Path $SourcePath -Destination "$DriveLetter\$DestinationFile" -ErrorAction Stop
    Write-Host "File copied successfully."
} catch {
    Write-Host "An error occurred: $($_.Exception.Message)"
} finally {
    if (Get-PSDrive -Name $driveName -ErrorAction SilentlyContinue) {
        Remove-PSDrive -Name $driveName -Force -ErrorAction SilentlyContinue
    }
}
